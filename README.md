# 上班鼓励器

桌面悬浮窗：按时薪实时显示今天已经赚了多少、还有多久下班。

- 钱可以换算成人民币、日元、越南盾等（实时汇率），或者换算成**能加多少升汽油**（大多伦多每日油价）
- 常驻显示明天油价是涨还是跌
- 天气：现在、下班时、明天、日出日落（加拿大环境部数据），下班要下雨会提醒带伞
- 今日签：每人每天一签，有签文、打工指数和宜忌
- 塔罗牌：韦特塔罗 78 张，自己选过去 / 现在 / 未来三张，生成提示词拿去问 AI 解读
- 午饭吃什么：大转盘，选项自己改，最近两次吃过的自动跳过
- 赛博圣杯：掷筊问事，圣杯 / 笑杯 / 阴杯，可开“连续三圣杯”模式
- 税后到手：按 2026 年安省税率估算扣税后的金额，也可以选税前或现金
- 桌宠：导入自己小猫的图，它会趴在悬浮窗上，跟着天气换动作，上班时长换零食喂它
- 双击切换迷你模式；右键打开设置
- **自动更新**：有新版会自己下载、重启，不用重新安装

## 安装（Windows）

1. 装 Python：到 <https://www.python.org/downloads/windows/> 下载，安装时勾选 **Add python.exe to PATH**，然后点 **Install Now**。
2. 下载本程序：点页面上方绿色的 **Code** 按钮 → **Download ZIP**，解压到一个固定的位置（比如"文档"里）。
3. 双击 **上班鼓励器.pyw** 打开，第一次会弹出设置，填好时薪和上下班时间就行。

想开机自动打开：在悬浮窗上右键 → 勾选"开机自启"。

## 安装（Mac）

1. 到 <https://www.python.org/downloads/macos/> 安装 Python，装完运行一次 Python 文件夹里的 `Install Certificates.command`。
2. 同样下载 ZIP 解压。
3. 打开"终端"，进入解压的文件夹，运行一次 `chmod +x Mac双击打开.command`。
4. 第一次在 `Mac双击打开.command` 上**右键 → 打开**，以后直接双击。

如果不想每次启动都打开终端，可在源码目录运行 `bash build-mac-app.command`，生成 **上班鼓励器.app** 后双击启动。构建需要 Apple Command Line Tools（`clang`）；应用须和源码文件保留在同一目录，不能只把 `.app` 移到其他位置。

启动脚本会在已安装 `certifi` 时使用其可信根证书包，避免 Python 默认证书尚未配置时无法获取天气、油价等 HTTPS 数据；不会关闭证书验证。仍建议按第 1 步配置 Python 证书。运行错误保存在源码目录的 `运行日志.log`，便于排查。

## 做自己的小猫（桌宠）

程序不自带小猫，导入一套图片就有了：右键悬浮窗 → 设置 → **宠物** → **导入素材…**，选放图片的文件夹。

### 要准备哪些图

每个动作一张或几张 **PNG**（不能是 JPG），按下面的名字命名。多张就是动画，按 `_1`、`_2`… 顺序播放。

|---|---|---|

| `eat_1.png` … | 吃东西 | 喂食后 |
| `play_1.png` … | 玩逗猫棒 | 玩逗猫棒时 |
| `sleep_1.png` … | 睡觉 | 下班后、休息日、深夜 |
| `happy_1.png` … | 开心 | 吃完、玩完、被点之后 |
| `click_1.png` | 被戳一下 | 鼠标点它 |
| `hungry_1.png` … | 饿了 | 饱腹太低 |
| `work_1.png` … | 上班敲电脑 | 上班时间 |
| `rain` / `snow` / `cold` / `hot` / `sunny` | 下雨、下雪、冷（≤0°C）、热（≥28°C）、晴天 | 跟着天气 |
| `loaf` / `look` / `knead` / `nap` | 揣手趴成面包、歪头张望、踩奶、侧躺打盹 | 平时随机出现，待一会儿 |

| `nap` / `upsleep` / `twitch` | 侧躺睡、四脚朝天睡、睡梦抽动 | 睡觉时和 `sleep` 轮换 |

头顶小特效（可选，16×16）：`fx_heart`、`fx_question`、`fx_exclaim`、`fx_anger`、`fx_note`、`fx_sweat`。

食物和玩具图标（可选）：`snack.png`、`freeze_dried.png`、`can.png`、`wand.png`。缺的动作用"平时"代替。

### 图片要求

- **任意大小都行**，程序会自动缩成 64×64 的像素风、统一成 16 色。
- 背景最好是**透明**或**纯绿色（#00FF00）**，会自动抠掉；白底也行，但被身体围住的白色可能抠不干净。
- **每张图里猫的大小和位置要一样**（同一个画布、脚踩同一条线），程序按"平时"那张统一缩放和对齐。

### 用 AI 生成

右键悬浮窗 → 设置 → **宠物** → **复制提示词**，把复制到的整段提示词连同照片一起发给能画图的 AI（比如 ChatGPT）。提示词里已经写好画风、绿色背景、大小对齐、全部 54 个动作的文件名和画法，以及怎么交付（能跑代码的 AI 会直接打包成 zip）。AI 会先总结宠物长相让你确认，再一批一批地画；只画第一批（13 个常用动作）就能用。

**照片准备 3–6 张：**

- 正面全身坐姿（最重要，所有动作以它为准）
- 侧面全身
- 脸部特写（看清眼睛颜色和脸上花纹）
- 花纹明显的部位（背、尾巴、爪子等）

光线自然、不加滤镜和美颜，照片里只有这一只。画好的 PNG 放进一个文件夹，再点 **导入素材…** 选它。

### 喂养规则

- 上班每 30 分钟得 1 个零食，每 2 小时得 1 个冻干，上满一天得 1 个罐头。
- 逗猫棒随时能玩，玩完 30 分钟后才能再玩。
- 饱腹和心情会慢慢下降，饿了小猫会可怜巴巴。左键点猫有反应，右键猫打开喂食面板。

## 常见问题

- **怎么更新？** 不用管。程序每 6 小时自己检查一次，有新版就自动换上并重启；也可以右键 → "检查更新"。
- **新版有问题？** 上一个版本备份在设置文件夹里的 `旧版备份.pyw`
  （Windows：`%APPDATA%\上班鼓励器`；Mac：`~/Library/Application Support/上班鼓励器`）。
- **我的设置会被更新覆盖吗？** 不会，设置存在上面那个文件夹，和程序文件分开。
